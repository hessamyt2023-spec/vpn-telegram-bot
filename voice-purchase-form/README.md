# لیست خرید صوتی

فرم «لیست خرید» (فایل PDF با تاریخ ۱۴۰۵/۰۷/۰۶) به صورت یک وب‌اپ: همان ستون‌ها
(ردیف، کالا، نوع، تعداد، توضیحات) و همان سربرگ (عنوان و تاریخ شمسی)، که با
**گفتار فارسی** پر می‌شود. بار اول، همان ۳۰ ردیف فایل PDF به عنوان نمونه باز می‌شود.

## اجرا

نیازی به نصب بسته ندارد؛ فقط Node.js:

```bash
cd voice-purchase-form
npm start          # یا: node serve.js
```

سپس در **Chrome** یا **Edge** آدرس <http://localhost:8080> را باز کنید، روی میکروفون
بزنید و اجازهٔ میکروفون را بدهید.

- تشخیص گفتار مرورگر فقط روی صفحهٔ امن کار می‌کند: `localhost` یا `https://`.
  برای استفاده با گوشی، پوشه را روی یک میزبان HTTPS بگذارید (GitHub Pages،
  Cloudflare Pages، Netlify یا هر هاست ساده). همهٔ فایل‌ها ایستا هستند.
- Chrome برای فارسی از سرور گفتار گوگل استفاده می‌کند، پس اینترنت لازم است. اگر
  پیام «سرویس تشخیص گفتار در دسترس نیست» آمد، اتصال یا فیلترینگ شبکه را بررسی کنید.
- Firefox تشخیص گفتار ندارد و Safari آیفون فارسی را پشتیبانی نمی‌کند. در این حالت
  در کادر «فرمان متنی» تایپ کنید یا با میکروفون کیبورد گوشی (مثلا Gboard) حرف بزنید؛
  همان فرمان‌ها اجرا می‌شوند.

## دو حالت پر کردن

**فرمان آزاد** — هر جمله یک فرمان است:

| بگویید | نتیجه |
| --- | --- |
| کالا صد نانو نوع عدسی تعداد دو توضیحات خازن | ردیف جدید: `100NF` · عدسی · 2 · خازن |
| پنج تا مقاومت صد اهم | ردیف جدید: «مقاومت 100 OHM»، تعداد 5 |
| تعداد سه | تعداد ردیف انتخاب‌شده (آخرین ردیف) را 3 می‌کند |
| ردیف دوازده توضیحات برای گزینه دو | توضیحات ردیف 12 |
| ردیف سه توضیحات پاک کن | خالی کردن یک خانه |
| ردیف پنج | انتخاب ردیف 5 |
| حذف ردیف آخر / ردیف سوم رو پاک کن | حذف ردیف |
| ردیف جدید | یک ردیف خالی |
| تاریخ امروز / تاریخ ششم مهر هزار و چهارصد و پنج | تاریخ شمسی فرم |
| برگرد | برگرداندن آخرین تغییر |
| انگلیسی / Persian | عوض کردن زبان گفتار (برای کد قطعه‌ها مثل ATMEGA8A) |
| تمام | خاموش کردن میکروفون |

کلمه‌های کلیدی خانه‌ها: «کالا» (یا «نام کالا»، «اسم»)، «نوع» (یا «پکیج»)،
«تعداد» (یا «مقدار»)، «توضیحات» (یا «توضیح»، «شرح»).
جملهٔ بدون «ردیف ...» که «کالا» داشته باشد ردیف تازه می‌سازد؛ جمله‌ای که فقط
نوع/تعداد/توضیحات دارد، ردیف انتخاب‌شده را تغییر می‌دهد.

**خانه به خانه** — خانهٔ نارنجی منتظر است؛ فقط مقدارش را بگویید
(کالا ← نوع ← تعداد ← توضیحات ← ردیف بعد). «بعدی» یا «خالی» رد می‌شود، «قبلی»
برمی‌گردد. با کلیک روی هر خانه، مکان‌نما به آن خانه می‌رود.

## تبدیل عدد و واحد

عددهای گفتاری به رقم تبدیل می‌شوند («هزار و چهارصد و پنج» ← 1405، «سوم» ← 3،
«یازده ممیز صفر پنج نه دو» ← 11.0592) و «آی سی» عدد ۳۰ حساب نمی‌شود. با گزینهٔ
«تبدیل واحدها»، واحدها به نگارش همین فرم درمی‌آیند:

| گفته | نوشته |
| --- | --- |
| صد نانو / بیست و دو پیکو | `100NF` / `22PF` |
| هزار میکرو بیست و پنج ولت | `1000UF/25V` |
| صد اهم / ده کیلو اهم | `100 OHM` / `10K OHM` |
| یازده ممیز صفر پنج نه دو مگاهرتز | `11.0592MHz` |
| دیپ بیست و هشت / تی او نود و دو | `DIP-28` / `TO-92` |
| بیست در ده میلیمتر / یک چهارم وات | `20*10 MM` / `1/4W` |

## ذخیره و خروجی

- همه‌چیز خودکار در همین مرورگر (localStorage) ذخیره می‌شود. چند فرم می‌توانید
  داشته باشید و از فهرست بالای صفحه بینشان جابه‌جا شوید.
- **خروجی اکسل (CSV)** با UTF-8 که اکسل فارسی را درست باز می‌کند.
- **چاپ** همان جدول فرم کاغذی را روی A4 چاپ می‌کند (یا با «Save as PDF» فایل PDF بسازید).

## فایل‌ها

| فایل | کار |
| --- | --- |
| `index.html`، `styles.css` | صفحه و ظاهر (راست‌به‌چپ، حالت تیره، نمای گوشی، چاپ) |
| `app.js` | وضعیت فرم، اجرای فرمان‌ها، برگرداندن، ذخیره، خروجی |
| `voice.js` | اتصال به Web Speech API با زبان `fa-IR` و روشن‌ماندن پیوسته |
| `parser.js` | تبدیل جملهٔ فارسی به فرمان: عدد، واحد، ردیف، تاریخ شمسی |
| `tests/parser.test.js` | تست‌های parser — اجرا با `npm test` |

---

**English summary.** A dependency-free web app that recreates the uploaded purchase-list
form (row, item, package type, quantity, notes, Jalali date) and fills it from Persian speech
via the browser Web Speech API (`fa-IR`; Chrome/Edge). `parser.js` turns utterances into
add/update/delete/select/date commands, converts Persian number words and electronics units
(`صد نانو` → `100NF`), and has a cell-by-cell mode. Data autosaves to localStorage; CSV
export and an A4 print layout are included. Run with `npm start`, test with `npm test`.
