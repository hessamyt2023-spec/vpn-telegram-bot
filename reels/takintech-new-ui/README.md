# ریلز رونمایی از UI جدید takintech.ir

خروجی: ویدیوی عمودی ۱۰۸۰×۱۹۲۰، ۳۰ فریم، ۳۲ ثانیه، H.264 + AAC، بلندی صدا ‎-14 LUFS‎ (استاندارد اینستاگرام).
همه‌چیز از روی کد ساخته می‌شود: موشن (HTML/JS که فریم‌به‌فریم با Chromium رندر می‌شود)، موزیک و افکت‌های صوتی (سنتز با numpy، بدون نمونهٔ صوتی و بدون مشکل کپی‌رایت)، نریشن (TTS فارسی یا صدای ضبط‌شدهٔ خودتان) و در پایان موشن لوگوی هگزانو.

## چه چیزهایی لازم است

| فایل | توضیح |
|---|---|
| `assets/screens/desktop-hero.png` | اسکرین‌شات بالای صفحهٔ اصلی در دسکتاپ (۱۴۴۰×۹۰۰) |
| `assets/screens/desktop-full.png` | اسکرین‌شات کامل و بلند صفحهٔ اصلی (برای صحنهٔ اسکرول) |
| `assets/screens/desktop-detail.png` | صفحه‌ای که روی یک بخشش زوم می‌کنیم؛ کادر زوم در `config.json → screens.detail_focus` (نسبی ۰ تا ۱) |
| `assets/screens/mobile-full.png` | اسکرین‌شات کامل نسخهٔ موبایل |
| `assets/screens/page-1..4.png` | چهار صفحهٔ دیگر سایت برای مونتاژ سریع |
| `assets/logo/hexano.svg` (یا `hexano.png`) | لوگوی هگزانو؛ با SVG افکت «کشیده‌شدن خطوط» اجرا می‌شود، با PNG افکت ریویل دایره‌ای |
| `assets/voice/narration.wav` *(اختیاری)* | یک تیک کامل نریشن روی تایم‌لاین ۳۲ ثانیه‌ای |
| `assets/voice/lines/01..07.wav` *(اختیاری)* | یا هر جمله جدا؛ خودکار سر زمانش قرار می‌گیرد |

اسکرین‌شات‌ها را می‌شود خودکار گرفت (روی سیستمی که سایت را باز می‌کند):

```bash
node scripts/capture.cjs https://takintech.ir /page-a /page-b /page-c /page-d
```

هر فایلی که نباشد با یک وایرفریم خاکستری با برچسب PLACEHOLDER جایگزین می‌شود تا با UI واقعی اشتباه نشود.

## ساخت

```bash
pip install numpy scipy          # یک بار
./build.sh                       # خروجی نهایی: out/takintech-new-ui-reel.mp4
./build.sh --draft               # پیش‌نمایش سریع‌تر
./build.sh --tts                 # نریشن با صدای عصبی مایکروسافت (pip install edge-tts)
node scripts/render.cjs --still 5.5,13,27.5   # چند فریم ثابت برای بررسی
```

| ۲۰ تا ۲۲ | مونتاژ ضرب‌دار چهار صفحه روی بیت | هر چی بخوای، با چند کلیک. |
| ۲۲ تا ۲۶ | تایپ آدرس، کلیک روی دکمه | همین حالا سر بزن: تکین‌تک دات آی آر. |

متن‌ها، رنگ‌های برند، زمان‌ها و صدای TTS همه در `config.json` قابل تغییرند.

## ساختار

- `scene/index.html`, `scene/reel.js`: موشن؛ هر فریم تابع خالص زمان است، پس رندر همیشه یکسان است. نقاط افکت صوتی هم از همین تایم‌لاین خروجی گرفته می‌شود تا صدا و تصویر هیچ‌وقت از هم جدا نشوند.
- `scripts/render.cjs`: رندر فریم‌ها با Playwright و ارسال مستقیم به ffmpeg.
- `scripts/sound.py`: موزیک ۱۲۰ BPM (Am–F–C–G)، ۲۰ نوع افکت (رایزر، ایمپکت، ویپ، تایپ، کلیک، شیمر و …)، داکینگ موزیک زیر صدا.
- `scripts/tts.py`: نریشن فارسی با `fa-IR-FaridNeural` یا `fa-IR-DilaraNeural`.
- فونت: [وزیرمتن](https://github.com/rastikerdar/vazirmatn) (OFL).
