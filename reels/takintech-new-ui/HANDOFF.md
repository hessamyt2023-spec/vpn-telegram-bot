# ادامهٔ کار در Claude Code: ریلز رونمایی UI جدید takintech.ir

> این فایل را در Claude Code روی کامپیوتر خودت (پوشهٔ `Desktop\clip`) باز کن و بگو:
> **«HANDOFF.md را بخوان و ریلز را تا خروجی نهایی کامل کن.»**

---

## هدف

یک ریلز عمودی جذاب برای پیج اینستاگرام takintech، دربارهٔ رونمایی از UI جدید سایت takintech.ir (تکین الکترونیک).
ویدیو باید نریشن فارسی و صداگذاری داشته باشد و در پایانش موشن لوگوی هگزانو بیاید.

## چرا کار به این‌جا منتقل شد

نسخهٔ اول در یک جلسهٔ ابری ساخته شد و آن محیط به این‌ها دسترسی نداشت:

- **سایت:** takintech.ir (سرور `195.28.169.27`، در ایران) از آن‌جا بسته بود.
- **هگزانو:** hexano.ir و app.hexano.ir هم باز نمی‌شدند.
- **فایل‌های محلی:** فایل‌های این کامپیوتر در دسترس نبودند؛ یعنی قالب سایت، لوگوی هگزانو و ریلز قبلی هگزانو.
- **صدای نریشن:** سرویس TTS مایکروسافت (`speech.platform.bing.com`) هم بسته بود.

برای همین موتور ساخت کامل آماده شده، ولی اسکرین‌شات‌ها و لوگو هنوز placeholder خاکستری هستند و نریشن هم هنوز ساخته نشده است.

## گرفتن کد

کد روی گیت‌هاب است: ریپوی `hessamyt2023-spec/vpn-telegram-bot`، شاخهٔ `claude/takintech-reels-clip-2kgegr`، پوشهٔ `reels/takintech-new-ui/`.

دو نکتهٔ محیطی از حافظهٔ پروژه:

- **OneDrive:** پوشهٔ `.git` را خراب می‌کند. یا خارج از OneDrive کلون کن، یا `core.autocrlf=false` بگذار.
- **شبکه:** Bash اینترنت ندارد؛ کارهای شبکه‌ای (git clone، npm، pip، capture، tts) را از PowerShell اجرا کن.

```powershell
cd $env:USERPROFILE\OneDrive\Desktop\clip
git -c core.autocrlf=false clone -b claude/takintech-reels-clip-2kgegr --single-branch https://github.com/hessamyt2023-spec/vpn-telegram-bot.git takintech-reels-src
Copy-Item -Recurse takintech-reels-src\reels\takintech-new-ui .\takintech-reels
cd takintech-reels
```

## کارهایی که مانده (به ترتیب)

### ۱. اسکرین‌شات‌های واقعی سایت

```powershell
node scripts/capture.cjs https://takintech.ir /shop /product/<یک-محصول> /blog /contact
```

- **مسیر صفحه‌ها:** مسیرهای واقعی را از قالب لوکال یا خود سایت پیدا کن. چهار صفحهٔ بعد از صفحهٔ اصلی می‌شوند `page-1..4.png` برای مونتاژ.
- **خروجی‌ها:** این فایل‌ها در `assets/screens/` ساخته می‌شوند: `desktop-hero.png`، `desktop-full.png`، `desktop-detail.png`، `mobile-full.png` و `page-1..4.png`.
- **صحنهٔ زوم:** یک بخش جذاب UI جدید را انتخاب کن (مثلاً هدر، کارت محصول یا هیرو). اسکرین‌شاتش را `desktop-detail.png` بگذار و کادرش را در `config.json → screens.detail_focus` به‌صورت نسبی (۰ تا ۱) تنظیم کن.
- **هشدار WAF:** درخواست‌های پشت‌سرهم از خط فرمان ممکن است IP را بلاک کند (مثل اتفاقی که برای takinelec افتاد). capture فقط چند صفحه را باز می‌کند، ولی آن را تکراری اجرا نکن.

### ۲. لوگوی هگزانو

- **کجا دنبالش بگرد:** در پروژه‌های هگزانو داخل `clip`، یعنی hexano-app/webapp، سایت hexano.ir («سفر کهکشانی») و ریلز قبلی هگزانو.
- **کجا بگذاری:** `assets/logo/hexano.svg`.
- **چرا SVG:** با SVG، خطوط لوگو تک‌تک کشیده می‌شوند و بعد پر می‌شوند. با `hexano.png` (پس‌زمینهٔ شفاف) فقط ریویل دایره‌ای اجرا می‌شود.
- **حرکت ریلز قبلی:** اگر ریلز قبلی هگزانو موشن لوگوی خودش را دارد، همان حرکت را در `upOutro()` در `scene/reel.js` بازسازی کن تا امضای برند یکسان بماند.
- **رنگ:** هویت هگزانو سیان روی `#121212` است. اگر لازم شد، رنگ‌های outro را به آن نزدیک کن.
- **جملهٔ زیر لوگو:** در `config.json → outro.tagline` است و فعلاً خالی است. از کاربر بپرس جمله‌ای مثل «طراحی و توسعه: هگزانو» بیاید یا نه.

### ۳. رنگ برند و متن‌ها

- **رنگ‌ها:** `config.json → brand.colors` را با پالت UI جدید سایت هماهنگ کن. رنگ‌ها را از CSS قالب لوکال یا اسکرین‌شات‌ها بردار.
- **نام برند:** «تکین الکترونیک» از قبل جایگزین «تکین‌تک» شده است. اگر پیج اینستاگرام نام دیگری به کار می‌برد، آن را بگذار.
- **لحن و هشتگ:** حافظهٔ `project_takintech_instagram.md` را بخوان و متن‌ها را با همان لحن تنظیم کن.
- **متن‌ها:** متن هر صحنه و نریشن در `config.json` است.

### ۴. نریشن

```powershell
python scripts/tts.py                              # صدای مردانه fa-IR-FaridNeural
python scripts/tts.py --voice fa-IR-DilaraNeural   # صدای زنانه
```

اگر صدای ضبط‌شدهٔ خود کاربر را می‌خواهی، دو راه هست:

- **یک تیک کامل:** فایل `assets/voice/narration.wav` روی تایم‌لاین ۳۲ ثانیه‌ای.
- **جمله‌به‌جمله:** فایل‌های `assets/voice/lines/01..07.wav`.

**این مسیر هنوز تست نشده،** چون در محیط ابری صدایی در دسترس نبود: دیکد صدا، تنظیم سرعت جمله‌ای که از بازه‌اش بلندتر است (`atempo` تا ۱.۳ برابر)، و کم شدن خودکار موزیک زیر صدا. بعد از اولین بیلد با صدا، حتماً به خروجی گوش کن.

### ۵. یک قاعدهٔ تایپوگرافی

طبق حافظهٔ پروژه، روی متن فارسی letter-spacing نباید باشد. این مورد اصلاح شده است؛ فقط روی دامنهٔ لاتین مانده. اگر متن تازه‌ای اضافه کردی، همین قاعده را رعایت کن.

### ۶. ساخت و بررسی

بیلد آفلاین است، پس از Git Bash هم کار می‌کند:

```bash
node scripts/render.cjs --still 1.2,5.5,9.5,13.5,17.5,21.6,24.7,27.4,29   # چند فریم ثابت برای چک
./build.sh --draft     # پیش‌نمایش سریع
./build.sh             # خروجی نهایی: out/takintech-new-ui-reel.mp4
```

قبل از تحویل این‌ها را چک کن:

- **منطقهٔ امن اینستاگرام:** متن‌ها نباید زیر UI اینستاگرام بروند. حدود ۲۵۰ پیکسل بالا و ۴۲۰ پیکسل پایین، و دکمه‌های سمت راست در نیمهٔ پایین.
- **زوم:** کادر `detail_focus` دقیقاً روی بخش موردنظر باشد.
- **صدا:** ریتم موزیک، بلندی افکت‌ها و وضوح نریشن را گوش کن. فعلاً صدا فقط با طیف‌نگار بررسی شده و هنوز کسی آن را گوش نکرده.
- **بلندی صدا:** حدود ‎-14 LUFS. `build.sh` خودش نرمال می‌کند.

### ۷. تحویل

- **ویدیو:** `out/takintech-new-ui-reel.mp4` (۱۰۸۰×۱۹۲۰، ۳۰ فریم، ۳۲ ثانیه، H.264 + AAC).
- **کاور:** یک فریم برای کاور پیشنهاد بده؛ مثلاً ثانیهٔ ۵.۵ (عنوان رونمایی + مرورگر) یا ۲.۷ (هوک).
- **کپشن:** کپشن اینستاگرام و هشتگ‌ها را بنویس، مطابق سبک پیج takintech.

## ساختار پروژه

| فایل | کار |
|---|---|
| `config.json` | ابعاد، BPM، رنگ‌ها، مسیر اسکرین‌شات‌ها و لوگو، متن صحنه‌ها و زمان‌بندی نریشن |
| `scene/index.html`, `scene/reel.js` | موشن. هر فریم تابع خالص زمان است (`window.__seek(t)`) و نقاط افکت صوتی را هم خروجی می‌دهد (`window.__CUES`) |
| `scripts/render.cjs` | رندر فریم‌به‌فریم با Playwright و ارسال مستقیم به ffmpeg؛ `--still`، `--draft` و `--cues-only` |
| `scripts/sound.py` | موزیک ۱۲۰ BPM (Am–F–C–G) و ۲۰ نوع افکت، همه سنتزی و بدون مشکل کپی‌رایت. داکینگ زیر نریشن و خروجی `build/mix.wav` |
| `scripts/tts.py` | نریشن با edge-tts، یک فایل برای هر جمله در `build/voice/` |
| `scripts/capture.cjs` | اسکرین‌شات دسکتاپ و موبایل از سایت زنده، با نام فایل‌هایی که config انتظار دارد |
| `build.sh` | زنجیرهٔ کامل: cues، صدا، رندر و میکس با loudnorm دومرحله‌ای |
| `assets/fonts/` | وزیرمتن (OFL) |

## وضعیت فعلی

- **انجام و بررسی شده:** فریم‌های ثابت همهٔ صحنه‌ها با placeholder، صدای ۳۲ ثانیه‌ای (طیف‌نگار و موج)، و بلندی صدا (‎-15.4 LUFS قبل از نرمال‌سازی؛ پیک ‎-1.6 dBFS). رندر کامل ویدیو هنوز روی این سیستم اجرا و بررسی نشده است.
- **انجام ولی تست‌نشده:** مسیر نریشن (TTS یا فایل ضبط‌شده) و `capture.cjs` روی سایت واقعی.
- **مانده:** اسکرین‌شات واقعی، لوگوی هگزانو، رنگ برند، نریشن، گوش دادن نهایی و رندر خروجی.
